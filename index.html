Project Overview

Digital Wellbeing & Focus Tracker — problem, objectives, and scope

Problem Statement

Students and young professionals spend a large, often unmeasured share of their day on entertainment and social apps, which crowds out focused study or work time and leaves people without a clear picture of where their hours actually go. Most people don't lack the desire to be productive — they lack visibility into their own habits and a simple way to build consistency day over day.

Objectives
  • Let a user log daily study, work, entertainment, social, and other screen activity in seconds.
  • Provide a distraction-free focus timer (Pomodoro-style) that automatically counts toward study time.
  • Turn raw logs into an at-a-glance dashboard: today's split, a 7-day trend, and a productivity score.
  • Let the user set personal study and screen-time goals and see live progress against them.
  • Surface plain-language insights and recommendations instead of just raw numbers.
  • Reward consistency with a day-streak so good habits compound over time.
Key Modules / Features
  • Dashboard — stat cards, category donut, productivity trend, streak, insights
  • Focus Timer — 25/50 min sessions, animated progress ring, auto-logging
  • Activity Tracker — add/remove activities by category and duration, with validation
  • Goals — editable daily study goal and screen-time limit, live progress bars
  • Weekly Analytics — 7-day study vs. screen-time chart and generated recommendations
Technologies & Tools
  • HTML5 for structure and semantic layout
  • CSS3 (custom properties / design tokens, Grid & Flexbox, responsive media queries)
  • Vanilla JavaScript (ES6) — DOM manipulation, event-driven view routing, no framework or build step
  • Browser localStorage for client-side persistence — works fully offline
  • Google Fonts (Fraunces + Manrope) for the type system
Expected Outcomes
  • A user can see, within seconds of opening the app, whether today is on track against their goals.
  • Logged data persists between visits with no account or backend required.
  • Completing focus sessions and hitting daily goals visibly builds a streak, reinforcing the habit.
  • Weekly analytics make it possible to spot patterns (e.g. entertainment creeping up) and self-correct.
Milestones
  • ✓ Design system & app shell (sidebar nav, 6 views, responsive layout)
  • ✓ Activity Tracker module — add/validate/remove logged activity
  • ✓ Focus Timer module — 25/50 min sessions, auto-logs to study time
  • ✓ Goals module — editable targets with live progress bars
  • ✓ Dashboard — stat cards, category donut, trend chart, streak, insights
  • ✓ Weekly Analytics — 7-day chart, averages, generated recommendations
  • ✓ Local persistence & light personalization (name, data survives reloads)
Scope & Design Decisions

This build is intentionally a client-side, single-user demo — a deliberate scope choice for a PBL prototype, not an oversight:

  • No backend/database: everything runs in one HTML file with localStorage, so it's gradeable and demoable instantly with zero setup. A production version would move this to a real database and API so data could sync across devices.
  • Manual activity logging, not OS-level tracking: automatically capturing real screen time requires a browser extension or native OS permissions that a sandboxed web page cannot access. Self-logging is used here as the in-scope substitute.
  • One local profile, not multi-user accounts: the name field personalizes the greeting but isn't authentication — there's no login, password, or server-side identity.
